# Security Policy

## Authorised use

msrf is a security-testing toolkit intended for assessing applications, devices and networks that you own or are explicitly permitted to test. Do not use it against systems without authorisation.

## Reporting a vulnerability

If you find a security issue in msrf itself, please open a private report via GitHub Security Advisories on the repository, or open an issue that describes the class of problem without a working exploit. We aim to acknowledge reports within a few days.

## Bundled third-party tools

msrf bundles MobSF, Frida, objection, mitmproxy and others; vulnerabilities in those belong upstream, but let us know if a bundled version needs updating.
